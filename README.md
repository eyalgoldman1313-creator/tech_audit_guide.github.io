# ביקורת מערכות מידע ממוחשבות בשילוב AI — מדריך לימוד

מדריך לימוד מלא לקורס **ביקורת מערכות מידע ממוחשבות בשילוב AI** (ד״ר אלון כהן, רו״ח, CISA, CRISC · שנה״ל תשפ״ו).
עמוד יחיד (single-file HTML), עברית מלאה (RTL), מותאם למובייל.

🔗 **האתר:** https://eyalgoldman1313-creator.github.io/tech_audit_guide.github.io/
📝 **אתר התרגול:** https://eyalgoldman1313-creator.github.io/tech_audit_practice.github.io/

## מה כלול

12 פרקים לפי סדר הסילבוס, כל נושא בכרטיס אחיד: במה מדובר · הסבר · מושגים מרכזיים · תפקיד המבקר · טבלאות השוואה · רשימות · ציטוטים מהתקנים · דגש לבחינה · "הופיע בבחינות" (עם קישור ישיר לקייס באתר התרגול).

1. התשתית הטכנולוגית
2. מבנה מערכות מידע והמערכת החשבונאית
3. תהליך הביקורת ותקני ביקורת (315 · 330 · 500 · 610 · 620 · 230 · 240 · 910/911)
4. בקרות כלליות (ITGC) ובקרות יישומיות
5. לשכות שירות, מיקור חוץ וענן (402)
6. אבטחת מידע וסייבר
7. המשכיות עסקית והתאוששות מאסון
8. מחזור חיים של מערכות מידע
9. מודלים לניהול בקרות פנימיות (COSO · CobiT · 3 קווי הגנה)
10. כלים וטכניקות ביקורת ממוחשבות ו-AI
11. חוקים ותקנות
12. אסטרטגיית מבחן

חיפוש מובנה בראש העמוד. תוכן שאינו מופיע בחוברת הקורס אך מופיע בסילבוס מסומן במפורש כ״השלמה״.

## מקורות
חוברת מערכי השיעור, סילבוס הקורס, פרסומים מקצועיים 2026 (תקני ביקורת), עמדת רשות ני״ע בנושא גילוי סייבר, מבחני הקורס לדוגמה (כולל מועדי 2026) ובחינות המועצה 2015–2025.

## מבנה ופיתוח
- `index.html` — האתר הבנוי (זה מה ש-GitHub Pages מגיש).
- `source/content/*.json` — תוכן הפרקים (פרק = קובץ).
- `source/build.mjs` — מחולל העמוד: `cd source && npm i marked@12 && node build.mjs` → `dist/index.html`.
